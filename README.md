# Clayens Aerospace : fichiers du hero

Fichiers servis par jsDelivr pour le hero 3D du site Clayens Aerospace (Webflow) : `hero.css`, `hero.js`, images du hero (`img/`) et modèles 3D (`3d/`).

Ce dépôt est généré par `site-clayens/webflow/outils/construire.py` : ne pas modifier les fichiers à la main. Chaque mise à jour est publiée sous une nouvelle étiquette de version (v1.0.0, v1.0.1...) et l'adresse de la page Webflow est mise à jour en conséquence.
